# Data files

Both files in this directory are **generated by `python reproduce.py`** and are
not maintained by hand. They contain no timestamps and no random content, so
regenerating them in the same environment reproduces them byte for byte.

## `record_minima_c5e6.csv`

The record minima of `Delta_k = (b - a)/c` over all primitive Pythagorean
triples with `c <= 5,000,000`, ordered by increasing hypotenuse. Corresponds to
Table 2 of the manuscript.

| column | meaning |
|---|---|
| `record_index` | 1-based position in the record sequence |
| `a` | smaller leg (`a < b`) |
| `b` | larger leg |
| `c` | hypotenuse |
| `leg_difference` | `b - a` |
| `delta_k_numerator` | numerator of `Delta_k` in lowest terms |
| `delta_k_denominator` | denominator of `Delta_k` in lowest terms |
| `delta_k_decimal` | decimal value to 12 places, for reading only |
| `c_times_delta_k` | exact value of `c * Delta_k` |

Every row satisfies `leg_difference = 1`, `delta_k_numerator = 1`,
`delta_k_denominator = c`, and `c_times_delta_k = 1`. These are outputs of the
computation, not constraints imposed on it.

The filename records the manuscript's bound. Running `reproduce.py` with a
smaller `--cmax` overwrites this file with the correspondingly shorter table
while keeping the same name; `reproduce.py` prints a note when that happens.

## `pell_spine_terms.csv`

The Pell-spine terms with `c <= 5,000,000`, generated from the integer
recurrences rather than by filtering the enumeration. Corresponds to Table 3 of
the manuscript (which additionally lists the convergents `s/n`).

| column | meaning |
|---|---|
| `index` | spine index `j`, starting at 1 |
| `a`, `b`, `c` | the triple, with `a < b` |
| `u` | `a + b`, satisfying `u^2 - 2c^2 = -1` |
| `leg_difference` | `b - a`, equal to 1 by definition of the spine |
| `delta_k_numerator` | 1 |
| `delta_k_denominator` | `c` |

The recurrences used are `c_{j+1} = 6 c_j - c_{j-1}` with seeds `c_0 = 1`,
`c_1 = 5`, and `u_{j+1} = 6 u_j - u_{j-1}` with seeds `u_0 = 1`, `u_1 = 7`.
The seed `c_0 = 1` is required by the recurrence and is not itself the
hypotenuse of a triple, so it does not appear in the file.
